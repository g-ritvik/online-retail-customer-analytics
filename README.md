# Online Retail Customer Analytics

## Motivation

Online retailers generate large volumes of transaction data that can reveal patterns in customer purchasing behavior, product performance, and sales across markets. Understanding these patterns can help businesses identify valuable customer segments, recognize purchasing trends, and make better-informed decisions about customer relationships and product offerings.

This project analyzes historical transaction data from a UK-based giftware retailer using the [UCI Online Retail II dataset](https://archive.ics.uci.edu/dataset/502/online+retail+ii). By examining customer purchasing behavior alongside product, sales, and geographic patterns, the project aims to develop a broader understanding of retail performance.

## Research Objective

To analyze customer purchasing behavior and sales performance to identify meaningful customer, product, and market patterns that can inform retail business decisions.

## Research Questions

1. Which customer segments generate the most revenue?
2. Which products contribute most to sales?
3. How frequently do customers purchase, and what distinguishes repeat customers?
4. How does purchasing behavior differ across countries?

## Research Approach

The planned analysis combines Recency, Frequency, and Monetary (RFM) customer segmentation with product performance, sales trend, and geographic analysis. Python and SQL will support data preparation and analysis, while Tableau is planned for presenting key findings through a dashboard.

An important part of the project is examining how these analytical perspectives can complement existing research on customer segmentation and purchasing behavior. The project's potential contribution will be refined through further literature review and analysis.

## Project Status

The project is in its initial development stage. The dataset has been downloaded, an exploratory data analysis notebook has been started, and an initial data dictionary has been created. This repository will document the project's code, decisions, and progress as the analysis develops.

## Dataset

**Source:** [UCI Machine Learning Repository — Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii)

The dataset contains historical transaction records from 2009–2011 for a UK-based online retailer specializing in unique giftware. It includes invoice, product, quantity, price, date, customer, and country information.
